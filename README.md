# 伤寒杂病论 · 研读

把《伤寒杂病论》桂林古本拆到每一条，把郝万山七十讲讲稿按方证自动归位，装进一个双击即用的桌面应用。

Flask + SQLite + 原生前端，PyInstaller 打包为单文件 exe：无控制台窗口，关窗即退后台。

## 功能

**原文**
- 34 篇、1330 条条文，逐条编号；原文 / 白话 / 按语三层分离，可按「纯原文、原文+白话、全展开」三档切换。
- 431 首方剂从条文中析出，组成、煎服法、功用、按语各自成块，可折叠；方名可点入详情，组成中的每味药可再点入药条。
- 篇首导读、篇末上下篇导航、阅读进度、字号缩放、纸色 / 夜读双主题、条文收藏（本地保存）。

**郝万山**
- 七十讲完整讲稿（约 70 万字）按讲次通读；每篇末尾自动聚合「本篇相关讲解」，按讲次折叠展开。
- 段落与病篇的对应关系由「病篇关键词 + 方名」打分得出，仅作索引，讲稿原文以讲次为准。

**中药**
- 从 431 首方剂中抽出 121 味药，1827 条方药关联。
- 每味药给出性味、归经、功效、主治、现代药理，以及「见于哪些方、见于哪些篇」的双向索引。

**脉学**
- 二十八脉独立成模块（浮沉迟数滑涩虚实长短洪微紧缓芤弦革牢濡弱散细伏动促结代疾），依《濒湖脉学》次序，按六纲、形质、气势、节律四组归类。
- 每脉给出指下体状、形成原理、主病、临床相关反应，以及**左右手寸关尺六部的分部所主**（左候心肝肾，右候肺脾命门）。
- **临床应用**分五层展开：辨证要点（辨虚实、辨兼夹）、兼脉辨治（96 组兼脉，如浮紧主风寒表实、弦细主肝肾阴虚）、治法方向、常见病证、类脉鉴别（浮与濡散、弦与紧长之别）。
- **静态脉图**：每脉一幅 SVG 图解，左侧以皮、肉、筋、骨四层标示脉管所在深浅（指下按到的层次），右侧按参数生成搏动波形——脉位定深浅、至数定疏密、张力定峰形、流利度定重搏、节律定歇止。洪脉来盛去衰、芤革中空如按葱管、散脉涣散无根、动脉关部独动、促结代各有止歇，波形按各自的指下之象生成，关键处（主波、重搏波、中空、歇止）以引线标注，不压曲线；总览页另有 28 张缩略小图可一眼比对。

**针灸**
- **十四经脉 · 361 穴**：十二正经加任督二脉，按流注次序编排。每经给循行原文、属络脏腑、主治概要、取穴要点，并列出本经**全部腧穴**（穴名、国际代码、定位、特定穴属性、主治）；五输、原络、郄、俞募、八会、八脉交会诸属性直接标在穴名旁。
- **石学敏醒脑开窍针法**独立成页：病机「窍闭神匿，神不导气」、治法、主方Ⅰ（大醒脑：内关·水沟·三阴交）与主方Ⅱ（小醒脑：内关·上星·百会·印堂·三阴交）、辅穴（极泉·尺泽·委中）、六步操作规范（刺法／手法／得气标准逐穴列明）、**手法量学**表（幅度、频率、时间、补泻方向）、十五类并发症配穴（吞咽困难、语言謇涩、手指握固、足内翻、共济失调、血管性痴呆、高血压、便秘等）、疗程与禁忌，另附三则病案。
- **临床应用**：十四类常见病（中风急性期／恢复期、面瘫、失眠、偏头痛、颈椎病、肩周炎、腰痛、胃痛、便秘、痛经、过敏性鼻炎、抑郁、肥胖）的主穴与随症加减；末附现代应用与证据强度分级。
- 穴位、经络全部接入检索：搜「内关」「足三里」「LI4」可直入该穴所在经络并高亮定位，搜「醒脑开窍」「石学敏」直达专页。

**检索**
- 全文检索覆盖条文、方剂、中药、脉象、穴位、经络、讲稿七类，FTS5 trigram 分词，中文两字词亦可命中；命中处上下文高亮，键盘 ↑↓ 选择、回车跳转。
- 方剂、中药、脉象等实体结果排在条文之前，顶部一排计数标签可直接跳到对应分组；中药可依药名、别名、性味、归经、功效、主治反查，脉象可依脉名、「弦脉」这类带「脉」写法、拼音、主病或兼脉反查（如「肝胆病」可查到弦脉）。

## 技术选型

| 层 | 选择 | 说明 |
| --- | --- | --- |
| 前端 | 原生 ES2022 + 现代 CSS | 零框架、零构建、零依赖，无运行时与 hydration，首屏即渲染 |

## 快速开始

```bash
pip install flask waitress beautifulsoup4 lxml pypdf pillow pyinstaller

# 1. 重建数据（约 3 分钟，需联网抓取原文并下载讲稿 PDF）
python tools/build_all.py

# 2. 本地调试
python tools/dev.py            # http://127.0.0.1:5057

# 3. 打包
python tools/make_icon.py
python -m PyInstaller --noconfirm --onefile --noconsole --name "伤寒杂病论研读" \
  --icon icon.ico --add-data "data/app.db;data" --add-data "web;web" app.py
```

## 数据处理

1. **原文**：按页面语义块解析 `seg-text / seg-formula / seg-decoction`，区分条文、方名、煎服法；组成行用「药名 + 剂量」规则判定，附于上方。
2. **讲稿**：按「第 N 讲」切分，清除页码与页眉，按句读切成 400–900 字段落。
3. **归属**：为每篇建立关键词表（病篇名、六经名、本篇全部方名），段落逐词加权计分；取讲次主导篇，得分不足者归「通论」。前 6 讲与第 70 讲为通论。
4. **中药**：从方剂组成串中切词，先按已知药名 / 别名做最长前缀匹配，再退回剥离剂量，避免「百合」被误拆为「百 + 合」。

## 数据来源

- 原文：易推智道经典书库《伤寒杂病论》桂林古本（白云阁藏本系统）<https://mmkat.com/book/shanghan-zabing-lun>
- 讲稿：郝万山讲《伤寒论》全 70 讲，民间中医网志愿者据课程录像逐句录入；视频合集 <https://www.bilibili.com/video/BV1QE411s7hT/>
- 中药性味归经、功效主治依《中药学》教材通行表述；现代药理仅列主要成分与已公认的作用方向。
- 二十八脉的脉名、体状、主病依李时珍《濒湖脉学》；左右手寸关尺分部所主、兼脉与治法参《中医诊断学》《中医内科学》通行表述。
- 十四经脉循行依《灵枢·经脉》，穴位定位取国家标准《经穴部位》，特定穴与主治参《针灸学》规划教材。
- 醒脑开窍针法的主方、辅穴、手法量学、并发症配穴与禁忌，据石学敏院士公开讲义与《醒脑开窍针刺技术规范》整理；病案据公开医案体例改写，隐去患者信息。
